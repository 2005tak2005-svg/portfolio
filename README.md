# portfolio

หน้าเว็บรวมผลงาน เครื่องมือ และกิจกรรมที่ผมสร้างเอง — หน้าเดียวจบ ส่งลิงก์ให้ HR เปิดดูได้เลย

ตอนนี้เป็น **แบบร่าง** ข้อความทุกจุดที่อยู่ในวงเล็บ `‹ … ›` คือช่องที่ต้องแก้
และช่องภาพทุกช่องยังว่างอยู่ รอไฟล์จริง

## ไฟล์ในโปรเจกต์

```
index.html            เนื้อหาทั้งหมดอยู่ไฟล์นี้ไฟล์เดียว
assets/css/style.css  หน้าตา สี ตัวอักษร การจัดวาง
assets/js/main.js     การเคลื่อนไหวตอนเลื่อนหน้า และการกดดูภาพขยาย
images/               รูปภาพทั้งหมด — อ่าน images/README.md ก่อนใส่ภาพ
```

ไม่มีขั้นตอน build ไม่ต้องลง Node ไม่มี dependency — ดับเบิลคลิก `index.html` ก็เปิดดูได้เลย

## เปิดดูบนเครื่องตัวเอง

ดับเบิลคลิก `index.html` ได้เลย หรือถ้าอยากให้เหมือนของจริงมากขึ้น

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## จะแก้ตรงไหน

| อยากแก้ | ไปที่ |
| --- | --- |
| ชื่อ, คำแนะนำตัว, ลิงก์ติดต่อ | `index.html` — บล็อกบนสุด กับหมวด `hero` และ `contact` |
| เพิ่ม / ลบ ผลงาน | `index.html` หมวด `work` — มีบล็อกตัวอย่างให้ก๊อปวางอยู่ท้ายหมวด |
| ใส่รูปภาพ | อ่าน `images/README.md` |
| สีและตัวอักษร | `assets/css/style.css` ข้อ 1 (`:root`) — แก้ที่เดียวเปลี่ยนทั้งเว็บ |
| ลบหมวดที่ไม่ใช้ | `index.html` — ลบทั้ง `<section>` นั้นทิ้งได้เลย แล้วลบลิงก์ในเมนูด้วย |

ขนาดผลงานแต่ละชิ้นคุมด้วย `data-span` บน `<article class="work">` ใส่ได้ 4 แบบ

- `full` — เต็มความกว้าง ใช้กับชิ้นเด่น
- `wide` — กว้าง 2 ใน 3
- `half` — ครึ่งหนึ่ง
- `narrow` — แคบ วางคู่กับ `wide` ได้พอดี

## เว็บจริงอยู่ที่ไหน

**https://2005tak2005-svg.github.io/portfolio/** — ลิงก์นี้ส่งให้ HR ได้เลย

เว็บขึ้นเองอัตโนมัติ ไม่ต้องกดอะไรใน Settings เพราะมีไฟล์
`.github/workflows/pages.yml` คอยทำให้ ทุกครั้งที่มีการ push เข้า branch `main`
GitHub จะเอาไฟล์ทั้งหมดขึ้นเว็บให้ใหม่ ใช้เวลาราวหนึ่งถึงสองนาที

แปลว่าเวลาจะอัปเดตเว็บ — ใส่รูป แก้ข้อความ เพิ่มผลงาน — แค่ push เข้า `main` พอ

ดูสถานะการอัปเดตแต่ละครั้งได้ที่แท็บ **Actions** บนหน้า repo
ถ้าขึ้นเครื่องหมายถูกสีเขียวคือขึ้นเว็บเรียบร้อยแล้ว

> ในหน้า **Settings → Pages** ช่อง *Source* จะแสดงว่า **GitHub Actions**
> อย่าเปลี่ยนกลับไปเป็น *Deploy from a branch* เพราะโหมดนั้น GitHub จะรัน Jekyll ทับ
> ซึ่งไม่จำเป็นกับเว็บที่เป็น HTML ล้วนแบบนี้

## หมายเหตุ

- รองรับมือถือ แท็บเล็ต และจอคอม
- ถ้าผู้ใช้ตั้งค่าเครื่องให้ลดการเคลื่อนไหว (reduce motion) หน้าเว็บจะหยุดอนิเมชันให้เอง
- ถ้าเบราว์เซอร์ปิด JavaScript เนื้อหายังอ่านได้ครบ แค่ไม่มีอนิเมชัน
