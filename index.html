เครื่องมือที่สร้างเอง

เขียนขึ้นเพื่อแก้ปัญหาหน้างานจริง ไม่ใช่งานฝึกหัด

เฟส 1 — จากไฟล์ไลฟ์ดิบ ถึงคลิปต่อสินค้า

  • ทีเด็ด = ขจัดปัญหาเลือกช่วงไลฟ์เอง
  • ระบบนี้รองรับการ loop engineering ให้เอไอจดและแก้ไขคำที่สคริปต์ถอดมาเพี้ยนได้ด้วยตัวมันเอง จากฐานความรู้/สิ่งที่เคยผิดจากรอบก่อน

เฟส 2 — จากคลิปดิบ ถึงคลิปพร้อมโพสต์

  • ทีเด็ด = ประหยัดเวลาคลีน raw file อีก 1 ขั้นพร้อมส่งไป CapCut
  • ใช้ฐานความรู้สินค้าที่ตกผลึกจากเฟส 1 มาปรับใช้กับเทรนด์คลิปสั้น เป็นแนวทางให้ content creator เลือกทำได้แบบไม่ต้องคิดเอง

  1. 01

    Node.js · ffmpeg · whisper.cpp

    video-understand

    ไลฟ์ขายของยาวเป็นชั่วโมง จะรู้ว่าใครพูดถึงสินค้าชิ้นไหนตอนไหน ต้องนั่งดูทั้งคลิปเอง

    ถอดเสียงคลิปทั้งไฟล์และหาช่วงเวลาที่พูดถึงสินค้าแต่ละชิ้นให้อัตโนมัติ ทำงานในเครื่องล้วน ไม่ส่งไฟล์ขึ้นคลาวด์ ไม่มีค่า API ต่อการรัน

  2. 02

    Node.js · ffmpeg · browser automation

    live-daily-cut

    หลังไลฟ์ขายของจบทุกวัน ต้องโหลดไฟล์ ฟังทวนทั้งไฟล์ แล้วตัดแยกเป็นคลิปทีละสินค้าเอง งานซ้ำเดิมที่กินเวลาหลักชั่วโมงทุกวัน

    ดาวน์โหลดไฟล์ไลฟ์ล่าสุดจากแดชบอร์ดให้เอง ถอดเสียง หาขอบเขตของแต่ละสินค้า แล้วเสนอรายการช่วงเวลาให้ตรวจก่อนตัดจริงเสมอ ต่อยอดจาก video-understand

  3. 03

    Node.js · whisper.cpp · Remotion

    reel-refiner

    คลิปต่อสินค้าที่ตัดมาแล้วยังมีช่วงเงียบเยอะและไม่มีคำบรรยาย ต้องมาตัดต่อและใส่ซับเองทีละคลิปก่อนโพสต์ได้

    ตัดช่วงที่ไม่มีคนพูดออกโดยดูจากบทพูดจริงแทนระดับเสียง แล้วเบิร์นคำบรรยายไทยที่จับจังหวะคำพูดลงคลิปให้อัตโนมัติ

  4. 04

    Node.js · Python

    capcut-draft

    คลิปที่ตัดต่อไว้แล้วอยากเอาไปแก้ต่อใน CapCut ปกติต้องนำเข้าไฟล์แล้วจัดวางคลิป เสียง คำบรรยายใหม่ทั้งหมดด้วยมือ

    สร้างไฟล์โปรเจกต์ CapCut ที่เปิดมาแล้วมีคลิป เสียง และคำบรรยายวางเรียงพร้อมแก้ไขต่อได้ทันที โดยไม่ต้องเรนเดอร์วิดีโอออกมาก่อน

  5. 05

    Swift · Apple Vision · Node.js

    product-diecut

    รูปสินค้าที่ถ่ายมาต้องตัดพื้นหลังออกก่อนเอาไปวางบนพื้นอื่นหรือทำกราฟิก ปกติต้องเปิดโปรแกรมตัดต่อรูปแล้วไล่ขอบเอง

    ตัดวัตถุออกจากพื้นหลังเป็นไฟล์ PNG โปร่งใสให้อัตโนมัติทีละรูปหรือทั้งโฟลเดอร์ ทำงานในเครื่องล้วน ไม่ต่อเน็ต
